# Image credits — Larkspur Studio (wordpress demo)

Larkspur Studio is a demonstration business built to show the Busymate AI WordPress
plugin — it is not a real design practice. Every photograph on this site is a freely
licensed image of a real place, used purely to illustrate a design mood; none of them
show work by Larkspur Studio, and no likeness or real brand is implied. Originals are
not committed here as originals — `img/*.jpg` are already-licensed renditions pulled
from Wikimedia Commons; this file records the source and licence for each.

# Image credits — `wix` demo

Unlike the self-hosted demos (ghost/wordpress/woo), this site's imagery is **not** sourced or
uploaded by this program — Wix hosts the page itself, and the site was built from a real,
published Wix template ("Bakery", Cafe & Bakery collection) rather than a from-scratch canvas.
Every photo currently on the live site is that template's own bundled stock photography,
licensed by Wix for use on any Wix-hosted site built from it (the same terms every real Wix
customer building on this template operates under).

No additional external image was sourced or uploaded for this pass. If a later pass swaps any
of the template's stock photos for a specifically-sourced free image (Unsplash/Pexels), it gets
listed here with its author + license + source URL, matching the ghost demo's `IMAGE-CREDITS.md`
convention.

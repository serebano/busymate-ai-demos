What changes once the bot is real

The same brain, knowledge and tools above — just reached the way Telegram's Bot API actually works.

1

A traveler messages first

A "Message us" link or a t.me/<bot> deep link opens Telegram with Nomad Circuits' bot pre-filled — the visitor always starts the conversation, never the shop.

2

Telegram's Bot API delivers it

The message arrives over Telegram's Bot API webhook, gets normalized into the same conversation shape as the web chat, and Watt answers from the same catalogue and policies shown above.

3

DM or group, your call

Watt can answer in a direct message or, in a group chat, only when mentioned — same assistant, same tools, scoped so it never talks over a group unasked.

Before you message us

A few things people ask first

Do you ship worldwide?
Yes, 3-7 business days, free over $75, a flat $6 under that.
Can I book a repair without buying anything?
Yes — walk in or message Watt to book a slot; the diagnostic is always free, no obligation.
Do your gadgets work with any country's plug or voltage?
The Everywhere Adapter covers 190+ countries, and most gadgets are dual-voltage (100-240V) already.
What if my device isn't on the repair list?
Message Watt with the device — most brands are fine; a few cases need an in-person look first.
Do you sell cables and cases too?
Yes, at the counter and by message — ask Watt.
Nomad Circuits is a demonstration shop. No order or repair is actually fulfilled, and the customer behind the sign-in button is not a real person.

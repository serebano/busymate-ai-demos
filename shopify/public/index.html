Since 2014 · Bellingham, WA

Twelve years of gear that gets repaired, not replaced.

Northline started in a garage, rebuilding tents the big brands had written off. The first thing we sold new was a rain shell redesigned after fixing three hundred broken ones.

Every product is tested by real people on real trips before it earns a price tag, and every one carries a lifetime warranty with a repair bench behind it. Buy once, fix when needed, hand it down.

      Under the hood

      This store runs the Busymate AI app for Shopify

      Northline is a sample storefront, but the assistant in the corner is the real thing — try each capability below, then see how to add it to your own site.

      1

      Answers from the catalog

      Grounded only in the twenty products and policies on this page — sizes, weights, temperature ratings, shipping and returns. It says so when it doesn't know.

      How to add this to your site →
      2

      Reads live store data over MCP

      The site's own MCP server exposes products and orders as callable tools — list_products, search_products, get_order_status, start_return — see /agents.json or /llms.txt.

      How to add this to your site →
      3

      Acts on the page itself

      Open the chat and say "add the rain shell to my cart" — the cart badge and drawer update in your own browser through WebMCP page tools. Then try "what's in my cart?".

      How to add this to your site →
      4

      Hands off to a person

      Type "I'd like to talk to a person". Anything outside the knowledge base routes to a teammate's inbox mid-conversation, without starting over.

      For agents too

      Machine-readable, on purpose

      Every tool above is also published for any LLM or MCP client that lands here without the widget.

      /llms.txt

      A plain-text summary of this site and its tools for a model that reads it first.

      /agents.json

      The tool list as structured JSON — names, schemas, and which ones need a signed-in visitor.

      /mcp

      A live MCP JSON-RPC endpoint any client can call directly, independent of the chat widget. The catalog is also at /catalog.json.

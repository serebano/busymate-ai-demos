# Busymate AI — demo sources

The source of every demo on **[demo.busymate.ai](https://demo.busymate.ai)** — each one a
full-feature reference of [Busymate AI](https://busymate.ai) on a real-looking site: grounded chat,
page actions over WebMCP, its own MCP server, a demo customer to sign in as, hand-off to a person,
and the machine-readable files (`llms.txt`, `agents.json`, `webmcp-catalog.json`) an agent reads.

Use a demo as the starting point for your own site: open the live demo, read the guide for that
integration, then copy the folder here. `_shared/` holds what every demo reuses (the MCP + identity
server, the form-card builder, the card and avatar UI, the brand and knowledge builders).
